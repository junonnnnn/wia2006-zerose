# FSKTMap · WIA2006 Presentation

Slides for **FSKTMap**, a 3D map that helps students navigate around the FSKTM campus.
Team Zero SE, WIA2006 System Analysis and Design.

**Live:** https://junonnnnn.github.io/wia2006-zerose/

## Presenting

- **→ / ←**, or click the right / left half of the screen, to change slides
- **F** for fullscreen
- Add `#3` to the URL to open slide 3
- Print to PDF for one 1920×1080 page per slide
